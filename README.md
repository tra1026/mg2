## Devlog
1. While I was writing the chest health code, Unity showed a CS1002 error saying that a semicolon was expected. The line that subtracts one from the health value was missing its semicolon. I added the semicolon at the end of the line and Unity compiled it without the error.
2. I think the period lets the code get to the 'color' setting that belongs to '_spriteRenderer'. I think 'new' makes a new Color using the values inside the parenthese. The 'r' means how much red ther is, and the two '0.2f' values set the green and blue amounts.
